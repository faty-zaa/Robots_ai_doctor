# RoboDoctor starter documentation

This bundle provides a small, source-grounded knowledge base to start indexing.

## Included

- `data/troubleshooting.md` — practical checks summarized from the official TurtleBot3 e-Manual.
- `data/robot_specs.md` — reference specifications and useful ROS topics.

## Setup

Copy the `data/` folder into the root of your RoboDoctor project, beside `main.py`, `ui.py`, and `pyproject.toml`.

These are concise summaries, not a downloaded or complete copy of the ROBOTIS manual.
